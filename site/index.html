Share it here.

Upload your script to a public GitHub release or repository you own. This form creates the catalog entry; GitHub handles the pull request.

  1. Choose the same .umc file you uploaded.
  2. Paste its public release or raw-file URL.
  3. Open the GitHub submission and create a pull request.

Checks run automatically. Accepted files are mirrored as release assets. No reviewer is required for valid plugin submissions.

The source account must match your GitHub account. Keep the same plugin ID for new versions.
